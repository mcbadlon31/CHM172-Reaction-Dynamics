# Quick Start Guide

## First-Time Users: Start Here!

Welcome to CHM172 Reaction Dynamics! This 5-minute guide will get you running your first simulation.

---

## Step 1: Open a Notebook (30 seconds)

Click this button to open Notebook 01 in Google Colab:

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/mcbadlon31/CHM172-Reaction-Dynamics/blob/main/notebooks/01_Collision_Theory.ipynb)

---

## Step 2: Run the Setup Cell (1 minute)

1. **Click the first code cell** (starts with `# GOOGLE COLAB SETUP`)
2. **Press Shift+Enter** or click the ▶️ play button
3. **Wait** for "✓ Setup complete!" message

> ⚠️ **First run only**: You may see a warning about "not authored by Google". Click "Run anyway" - this is normal for third-party notebooks.

---

## Step 3: Run All Cells (2 minutes)

From the menu: **Runtime → Run all**

Alternatively, press **Ctrl+F9** (Windows) or **Cmd+F9** (Mac)

---

## Step 4: Explore the Interactive Widgets

Scroll down to find sliders and input boxes. Try:
- Changing **Temperature** (T) from 300K to 600K
- Adjusting **Activation Energy** (Ea)
- Observing how the **reaction rate** changes
